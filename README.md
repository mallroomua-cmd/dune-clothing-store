# 🛍️ ШопінгМаркет — Shopify CSV Landing & E-Commerce Storefront

Сучасний, конверсійний та повністю адаптивний інтернет-магазин (лендинг) на React + Vite + Tailwind CSS із вбудованою панеллю керування, імпортом товарного фіда формату Shopify CSV та інтеграцією рекламних тегів Google.

---

## ⚡ Основні можливості

- **🇺🇦 Повна українська локалізація:** Інтерфейс, форми замовлення, повідомлення та валюта (₴).
- **📂 Зручне завантаження товарів через CSV:**
  - Drag & Drop імпорт стандартного експорту товарів `products_export.csv` від Shopify.
  - Автоматичне групування за `Handle` / `Title`, підтримка мульти-фотографій, варіантів, описів та знижок.
  - Збереження каталогу в `localStorage` браузера.
- **📊 Інтеграція Google Ads, GA4 та Merchant Center:**
  - **Google Analytics 4:** Потокове відстеження e-commerce подій (`view_item`, `add_to_cart`, `begin_checkout`, `purchase`).
  - **Google Ads:** Відстеження конверсій покупки (`conversion` з передачею суми та валюти).
  - **Google Merchant Center:** Підтвердження сайту через мета-тег у шапці.
  - **Live Event Debugger:** Вбудована консоль для перевірки спрацьовування тегів у реальному часі.
- **🚀 Висока конверсія (UI/UX Pro Max):**
  - Оформлення замовлення «В 1 клік».
  - Повноцінний бічний кошик покупок.
  - Швидка фільтрація за категоріями, пошук у реальному часі та сортування.
  - Доставка Новою Поштою та Укрпоштою з можливістю оплати при отриманні.
- **📋 Вбудована адмін-панель:** Перегляд отриманих замовлень, оновлення фіда, тестування конверсій.

---

## 🛠️ Стек технологій

- **Frontend:** React 19, TypeScript, Vite
- **Стилізація:** Tailwind CSS, Lucide React Icons
- **Парсер:** PapaParse (швидкий клієнтський парсинг без потреби у важкому бекенді)
- **Шрифтова пара:** Rubik + Nunito Sans

---

## 💻 Швидкий запуск

```bash
# Встановлення залежностей
npm install

# Запуск локального сервера
npm run dev

# Збірка для продакшн
npm run build
```
