# 🛍️ ШопінгМаркет — Shopify CSV Landing & E-Commerce Storefront

Сучасний, конверсійний та повністю адаптивний інтернет-магазин (лендинг) на React 19 + TypeScript + Vite + Tailwind CSS із вбудованою панеллю керування, імпортом товарного фіда формату Shopify CSV, сповіщеннями в Telegram та повною підтримкою Google Ads / GA4 / Google Merchant Center.

---

## ⚡ Основні можливості

- **🇺🇦 Повна українська локалізація:** Інтерфейс, форми замовлення, маска номера телефону (`+380`), швидкі міста доставки та валюта (₴).
- **📂 Необмежене завантаження товарів через CSV (IndexedDB):**
  - Drag & Drop імпорт стандартного експорту товарів `products_export.csv` від Shopify.
  - Збереження в **IndexedDB** — без лімітів пам'яті (підтримує 10 000+ товарів із фотографіями та HTML-описами).
  - Автоматичне групування за `Handle` / `Title`, підтримка мульти-фотографій, варіантів, описів та знижок.
- **📊 Повна аналітика та Google Ads Enhanced Conversions:**
  - **Enhanced Conversions:** автоматична передача нормалізованого номера телефону та міста клієнта в Google Ads для точного навчання Smart Bidding.
  - **Google Analytics 4:** e-commerce події (`view_item`, `add_to_cart`, `begin_checkout`, `purchase`).
  - **Google Merchant Center:**
    - Автоматична генерація мікророзмітки **Schema.org/Product (JSON-LD)** для кожного товару.
    - Вбудований **експорт XML фіда Google Shopping (RSS 2.0)** в один клік прямо з адмін-панелі.
    - Вставка мета-тегу перевірки сайту.
- **🤖 Серверна обробка та сповіщення в Telegram:**
  - Серверлес функція `api/order.ts` (Vercel) для безпечної відправки заявок у Telegram без витоку секретного токену бота у фронтенд.
  - **Offline Outbox Pattern (IndexedDB):** якщо зв'язок втрачено або бекенд тимчасово недоступний, замовлення ставиться в чергу `shopify_pending_orders` та автоматично відправляється при відновленні інтернету або за фоновим інтервалом.
  - **Анти-бот захист:** Honeypot пастка (`website`) + часовий фільтр (< 1 сек) для відсікання автоматичного спаму.
- **🔒 Безпека та захист адмін-панелі:**
  - Вхід до кабінету торговця захищено **PIN-кодом** (за замовчуванням `1234`, з можливістю зміни в налаштуваннях).
  - Захист від XSS через `DOMPurify` для HTML-описів товарів та екранування `\u003c` у Schema.org JSON-LD.
- **🚀 Оптимізація конверсії (CRO):**
  - Оформлення замовлення «В 1 клік» з мобільною плаваючою смужкою (Sticky Bottom Bar).
  - Повноцінний бічний кошик покупок з прогрес-баром безкоштовної доставки.
  - Розумна маска номера телефону `+380 (XX) XXX-XX-XX`.
  - Швидкий вибір популярних міст України (Київ, Львів, Одеса, Дніпро, Харків).
  - Тригери залишку («Залишилося 3 шт.») та бейджі знижок.
  - Пагінація каталогу з кнопкою «Показати ще товари».

## 🛠️ Стек технологій

- **Frontend:** React 19, TypeScript, Vite
- **Стилізація:** Tailwind CSS, Lucide React Icons
- **Сховище:** IndexedDB (без ліміту 5MB, швидке кешування) + localStorage для персональних налаштувань
- **Бекенд / API:** Vercel Serverless Functions (`api/order.ts`)
- **Парсер:** PapaParse з авто-видаленням UTF-8 BOM та підтримкою Multi-Options (`Option1 / Option2 / Option3`)
- **Шрифтова пара:** Rubik + Nunito Sans

## 🔑 Змінні середовища (`.env`)

Для налаштування серверної відправки замовлень у Vercel / локально створіть `.env`:

```env
# Серверні змінні (Vercel Serverless API)
TG_BOT_TOKEN="123456789:ABCdefGHIjklMNOpqrsTUVwxyz"
TG_CHAT_ID="987654321"

# Клієнтські дефолтні налаштування (за бажанням)
VITE_GA_ID="G-XXXXXXXXXX"
VITE_ADS_ID="AW-XXXXXXXXX"
VITE_ADS_LABEL="AbCdEf123456789"
VITE_ADMIN_PIN="1234"
```

## 📦 Розгортання (Деплой)

Репозиторій повністю підготовлений для автоматичного деплою на Vercel в 1 клік:
- Підтримує як клієнтський SPA роутинг, так і серверлес ендпоінт `/api/order`.
- Конфігурація збережена у `vercel.json`.
