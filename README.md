# 🛍️ Stiletto / ШопінгМаркет — Luxury Skincare & E-Commerce Storefront

Сучасний, конверсійний та високошвидкісний інтернет-магазин преміальної косметики на **React 19 + TypeScript + Vite + Tailwind CSS** з редакційним дизайном (Stiletto / Dune editorial style), вбудованою повноцінною CRM-панеллю керування, віджетом зв'язку **«Написати нам» (Telegram / Viber)**, движком промокодів, імпортом/експортом товарного фіда формату Shopify CSV, сповіщеннями в Telegram та інтеграцією з рекламними мережами.

---

## ⚡ Основні можливості вітрини (11/10)

- **💬 Плаваючий віджет «Написати нам» у правому кутку:**
  - Швидкий вибір: **Telegram**, **Viber** або прямий телефонний дзвінок.
  - Індикатор статусу підтримки: *«🟢 Менеджер онлайн • відповідь за 2 хв»*.
  - Автоматичне підлаштування під мобільний екран без перекриття нижньої кнопки замовлення.
  - Повне керування посиланнями та номерами в панелі налаштувань.
- **🎟️ Движок промокодів & знижок:**
  - Підтримка відсоткових (`-15%`) та фіксованих (`-100 ₴`) знижок з мінімальним порогом замовлення.
  - Інтерактивне застосування коду в кошику та чек-ауті з миттєвим перерахунком суми.
  - Автоматична передача промокоду та розміру знижки в Telegram-повідомлення та CRM.
- **🔍 Миттєвий розумний пошук (Live Search):**
  - Виклик клавішею `/` або `Ctrl/Cmd + K`.
  - Миттєва фільтрація каталогу за назвою, категорією, описом та тегами.
- **💖 Список бажань (Wishlist):**
  - Кнопки додавання в обране на картках і у вікні товару.
  - Лічильник у шапці та зручна бічна панель для збережених товарів.
- **🚚 Відділення Нової Пошти & Прогрес-бар доставки:**
  - Інтерактивний вибір міст та відділень Нової Пошти.
  - Динамічний розрахунок залишку до безкоштовної доставки з візуальним прогресом у кошику.
- **✨ Social Proof сповіщення («Щойно купили»):**
  - Ненав'язливі живі повідомлення про замовлення з каталогу магазину для підвищення довіри та конверсії.
- **📜 Історія переглянутих товарів:**
  - Фіксація переглядів користувача в редакційному блоці перед футером сайту.
- **📄 Політики та стандарти (Mistorely / Cosibella):**
  - Повні юридичні сторінки українською: Оплата і доставка, Обмін та повернення 14 днів, Договір оферти, Конфіденційність, Про нас.

## 🎛️ Повноцінна панель керування (Admin Control Hub)

Доступ здійснюється через додавання `#admin` до адреси сайту або через кнопку **SYS ADMIN** у футері (захищено PIN-кодом, за замовчуванням `1234`). Панель розділена на 5 робочих модулів:

1. **📦 Товари (`products`):**
   - Каталог товарів з фільтрацією за наявністю, категоріями та пошуком.
   - Швидке інлайн-редагування цін та акційних цін без перезавантаження.
   - Кнопка **«Дублювати товар»** (створення копії в 1 клік).
   - Створення та редагування товарів, додавання тегів на лету.
2. **📊 Замовлення (`orders` / CRM):**
   - Управління статусами замовлень (Нове, Підтверджено, Відправлено, Виконано, Скасовано).
   - **Номер ТТН:** внесення та збереження експрес-накладної Нової Пошти / Укрпошти.
   - **«📋 Копіювати для НП»:** швидке копіювання даних одержувача для додатку Нової Пошти.
   - **«📥 Експорт CSV»:** вивантаження всіх замовлень у структурований файл Excel/CSV (UTF-8 BOM).
   - Моніторинг черги Outbox та ручна повторна відправка сповіщень.
3. **⚙️ Налаштування & Промо (`settings`):**
   - Контакти магазину: телефон, Telegram, Viber, Instagram, графік роботи, поріг безкоштовної доставки.
   - Тумблери плаваючого віджета зв'язку та сповіщень Social Proof.
   - Створення та керування промокодами (код, тип знижки, розмір, мінімальний чек).
   - Форма зміни PIN-коду адміністратора.
4. **🗄️ Фід & Імпорт/Експорт (`feed`):**
   - Drag & Drop імпорт стандартного CSV-файлу Shopify без обмежень пам'яті (IndexedDB).
   - Експорт каталогу назад у формат Shopify CSV.
   - Генерація XML фіда Google Merchant Center (Google Shopping RSS 2.0).
5. **🎯 Маркетинг & Інтеграції (`marketing`):**
   - Підключення Telegram Bot Token та Chat ID.
   - Налаштування Google Analytics 4, Google Ads, Meta Pixel.
   - Вбудований **Live Debugger** для відстеження e-commerce подій у реальному часі.

## 🛠️ Стек технологій

- **Frontend:** React 19, TypeScript, Vite
- **Стилізація:** Tailwind CSS, Lucide React Icons
- **Сховище:** IndexedDB (для 10 000+ товарів та черги замовлень) + localStorage
- **Код-спліттінг:** `React.lazy` для адмінки та важких модалок (оптимальний початковий JS)
- **Бекенд / API:** Vercel Serverless Functions (`api/order.ts`)
- **Тестування:** Власний тестовий набір на `jiti` з перевіркою парсерів, розрахунків кошика, безпеки та стійкості до відмов
